# สมุดเพลงเชียร์ เทพศิรินทร์พุแค

หน้าเว็บนักเรียน ฝากบน GitHub Pages ข้อมูลเพลงมาจากไฟล์ `data/songs.json`
ซึ่งระบบในชีตเป็นคนเขียนให้ (เมนู เพลงเชียร์ > เผยแพร่เพลงขึ้นเว็บ) ไม่ต้องแก้ไฟล์นี้เอง

## ติดตั้งครั้งแรก
1. เปิด repo `debsirin-songs` > Add file > Upload files
2. ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ลงไป (index.html, sw.js, manifest.webmanifest, assets, data) > Commit changes
3. Settings > Pages > Source: Deploy from a branch > Branch: main / (root) > Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://ชื่อบัญชี.github.io/debsirin-songs/`
5. นำลิงก์นี้ไปใส่ที่ SITE_URL ในชีต Settings
6. กดเผยแพร่จากชีต เพื่อแทนที่ข้อมูลตัวอย่างด้วยเพลงจริง

## โครงสร้าง
- `index.html` หน้าเว็บ
- `assets/` สไตล์ สคริปต์ ตราโรงเรียน ไอคอน
- `data/songs.json` ข้อมูลเพลง (ระบบเผยแพร่เขียนทับ)
- `audio/` ไฟล์ MP3 (หน้าผู้ดูแลอัปโหลดให้)
- `sw.js` เก็บหน้าเว็บไว้ในเครื่อง เปิดได้แม้เน็ตในสนามไม่ดี

## เมื่อแก้ไฟล์หน้าเว็บ (index.html, assets)
เปลี่ยนเลข `VERSION` บรรทัดแรกของ `sw.js` ด้วย เช่น `songbook-v2`
ไม่อย่างนั้นเครื่องที่เคยเปิดเว็บจะยังเห็นหน้าเดิมอีกหนึ่งรอบ

## โหมดฉายขึ้นจอ (ปุ่ม "ฉายขึ้นจอ" ในหน้าเพลง)
- ถัดไป: ลูกศรขวา/ลง, PageDown, Space, Enter, แตะจอ, ปัดซ้าย (คลิกเกอร์นำเสนอใช้ได้ทันที)
- ก่อนหน้า: ลูกศรซ้าย/ขึ้น, PageUp, แตะขอบซ้ายของจอ, ปัดขวา
- M สลับทีละท่อน/ทั้งเพลง   B จอดำ   Q คิวอาร์โค้ดกลางจอ   F เต็มจอ   Esc ออก
- กดถัดไปที่หน้า "จบเพลง" จะฉายเพลงถัดไปต่อทันที

## หน้าพิมพ์ QR
- `#/qr` QR ทุกเพลงบน A4 (หน้าผู้ดูแลมีปุ่ม "พิมพ์ QR ทุกเพลง")
- `#/qr/รหัสเพลง` โปสเตอร์ A4 ของเพลงเดียว
